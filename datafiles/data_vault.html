FILE

A collection of related records treated as a unit and stored under the same file name (e.g., STUDENTS.txt).

RECORD

A complete entry about one topic or one person within a file (spans multiple consecutive lines in ICS3U files).

FIELD

An area within a record which contains one specific type of information (e.g., Name, Age, Grade, Homeroom — each on its own line).

// Standard ICS3U NetBeans File Reading Pattern
try {
    // Relative path inside project's src folder (never C:\Users\...!)
    File file = new File("src/packagename/data.txt"); // or "src\\packagename\\data.txt"
    Scanner scanner = new Scanner(file);

    while (scanner.hasNextLine()) {
        String name = scanner.nextLine();               // Read String field
        int age = Integer.parseInt(scanner.nextLine()); // Read & parse int field
        double pay = Double.parseDouble(scanner.nextLine()); // Parse double field
    }
} catch (FileNotFoundException e) {
    System.out.println("Error: " + e);
}

⚠️ Common ICS3U Pitfalls

  • Integer Division: double x = 1 / 2; stores 0.0! Cast first: (double) 1 / 2.
  • Absolute Paths: "C:\\Users\\..." fails on your teacher's computer. Always start with "src/...".
  • Search Overwrite: Set status = "Not Found" before the loop; never reset it in an else inside the loop!
