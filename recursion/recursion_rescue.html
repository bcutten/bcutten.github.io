Recursion Field Guide

1. Base Case (The Stopping Condition)

The simplest instance of the problem that can be solved directly without making another recursive call. Without a reachable base case, recursion never terminates. 

if (n <= 1) return 1; // Stops recursion immediately

2. Recursive Step (Progress Toward Base Case)

The method calls itself with a modified argument that moves strictly closer to the base case (e.g., n - 1, n / 10, or s.substring(1)). 

return n * factorial(n - 1); // Subproblem is smaller by 1

3. The JVM Call Stack (LIFO)

Every method invocation pushes a brand-new Stack Frame onto the JVM Call Stack containing its own independent parameters, local variables, and return address. Frames are popped in Last-In, First-Out (LIFO) order.

4. Winding vs. Unwinding Phases

  • Winding (Going Down): Code before the recursive call executes as frames are pushed onto the stack.
  • Unwinding (Coming Back Up): Code after the recursive call (or pending return expressions) stays paused until the child frame returns a value.

5. Java StackOverflowError

If the base case is missing or the recursive argument moves away from the base case (e.g., calling factorial(n + 1)), stack frames accumulate until the JVM runs out of call stack memory and throws java.lang.StackOverflowError.
